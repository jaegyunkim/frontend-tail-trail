# frontend-tail-trail · 꼬리길(TailTrail) 모바일 웹

오늘 우리 강아지가 **나가도 되는지**, 몇 시에 몇 분 걸을지, 어디로 갈지, 가까운 **공원·동물병원·미용·애견샵**과 **응급 병원**까지 한 화면에 알려 주는 애견 산책 도우미입니다.

- 주소: https://jaegyunkim.github.io/frontend-tail-trail/
- 백엔드: 비공개 `jaegyunkim/backend-tail-trail` (맥미니 `127.0.0.1:8889`, Caddy HTTPS `/tail-trail/`)
- 틀: `frontend-book-walking`(로그인·세션 `auth.js`, 이용 신청, 관리자, 접속 현황, 출발지 고르기, 디자인 토큰)을 그대로 쓰고 강아지 화면을 더했습니다.

## 화면
- **오늘**: 우리 아이 → 출발지 → 날짜 → `오늘 산책 판단하기`. 결과는 판단 카드(지금 가기/시간대 바꾸기/짧게/실내), 점수·기온·노면 최고(추정), 시간대별 막대(06~21시), 산책 예정일 날씨, 가까운 공원, 코스(시작점에서 N km 왕복), 응급·동물병원·애견 미용·애견샵(인허가 확인·전화·지도·길찾기), 반려동물 동반 가능 장소(동반 구분·견종·필요 사항)
- **주변**: 공원·동물병원·동물약국·미용·애견샵·펫호텔/유치원 목록(**인허가 확인** 표시: 행정안전부 영업 중 등록 업소와 일치), `응급 · 가까운 동물병원 찾기`
- **동물보호소**: 기준 지역 또는 다른 시·군·구의 최근 보호견 공고, 센터 연락처, 입양 전 준비와 절차를 확인해요. 공고와 실제 입양 가능 여부는 다를 수 있어 센터에 먼저 문의해요.
- **꼬리일기**: 장소·아이·날짜·시간·기분·배변·한 줄, 이어 걷기·이번 달·최근 30일 통계
- **우리 아이**: 처음 등록 · 추가 등록 · 수정 · 삭제 · 기본 아이 지정(최대 5마리). 이름·크기·나이·단두종·두꺼운 털만 받고 견종·사진은 받지 않습니다
- **의견**, 내 판단 기록(머리줄 시계 버튼), `admin.html`(어디물어 관리자와 같은 메뉴: 신청 승인·AI 연결·사용자·세션·사용량·접속현황·대화 로그·로그인 기록·리포트·스킬·의견 보내기·작업 기록 + 꼬리길 전용 플랜·코스)

## 설정
- `config.js`의 `TAILTRAIL_API`(기본 `https://lonbekim.tplinkdns.com/tail-trail`)
- 다른 서버를 시험할 때는 `?api=http://127.0.0.1:8889`(브라우저에 저장됩니다)
- 비밀키는 넣지 않습니다.

## 로컬 실행
```bash
python3 -m http.server 8182   # 백엔드 ALLOWED_ORIGINS 에 http://localhost:8182 포함
npm test
```
